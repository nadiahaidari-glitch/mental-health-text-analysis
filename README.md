# mental-health-text-analysis
# Mental Health Data Analysis Project

## Project Overview

This project studies mental health text data to understand emotional patterns in online posts.

The project focuses on posts related to:

* suicide
* depression
* stress
* loneliness
* emotional wellbeing

The goal is to use data analysis and visualization to better understand mental health discussions and emotional language patterns.

---

## Problem

Mental health problems are increasing around the world. Many people share their emotions and struggles online, but it can be difficult to recognize warning signs early.

This project explores how text data can help identify emotional distress and negative mental health patterns.

---

## Dataset

The dataset was taken from Kaggle and contains online posts labeled as:

* Suicide
* Non-Suicide

Dataset link:

[Kaggle Suicide Watch Dataset](https://www.kaggle.com/datasets/nikhileswarkomati/suicide-watch?utm_source=chatgpt.com)

---

## Project Features

The project includes:

* Data cleaning
* Exploratory Data Analysis (EDA)
* Word frequency analysis
* Emotional word comparison
* Sentiment analysis
* Data visualization

---

## Main Findings

The analysis showed that suicidal posts often contain more negative emotional words such as:

* sad
* alone
* hopeless
* pain

The project also found strong emotional patterns related to stress, depression, and loneliness.
